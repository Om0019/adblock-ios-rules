# AdBlock iOS DNS Rules

Custom DNS proxy adblocking rules for iOS AdBlock (by FutureMind).

## 📥 Direct Import URL (Raw)

```
https://raw.githubusercontent.com/Om0019/adblock-ios-rules/main/ios-dns-rules.adblock
```

## 📱 How to Use in iOS AdBlock

1. Open the **AdBlock** app on your iOS device.
2. Go to **Settings** > **Import DNS rules**.
3. Paste the direct raw URL above (or import the downloaded `.adblock` file).
4. Select the **`0.0.0.0, ::`** target group.
5. Save and restart AdBlock protection if prompted.
